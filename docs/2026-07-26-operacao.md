- Linux (lab WSL ou servidor Debian)
- **Node.js 20+** e npm

## 4. Variáveis de ambiente

Fonte de verdade: **`.env.example`** (raiz), **`workers/sir-ingest/.env.example`** e **`workers/tmip/.env.example`**.

Validação: `npm run env:check` (paridade example ↔ local, ordem e comentários; `SIR_DB_*` igual entre Next e workers).

| Bloco     | Chaves                                                                                        | Uso                                                 |
| --------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| MySQL SIR | `SIR_DB_HOST`, `SIR_DB_PORT`, `SIR_DB_USER`, `SIR_DB_PASSWORD`, `SIR_DB_NAME`                 | Next (leitura + tratativas/SDH) e workers (escrita) |
| MySQL HFC | `HFC_DB_*`                                                                                    | Leitura `tbl_inventory_pme` (BSOD)                  |
| TMIP SFTP | `SFTP_HOST`, `SFTP_PORT`, `SFTP_USER`, `SFTP_PASSWORD`, `SFTP_REMOTE_PATH`, `SFTP_LOCAL_PATH` | Worker `workers/tmip` (planilha SDH)                |
| App       | `PORT`, `APP_PUBLIC_URL`                                                                      | Next.js                                             |
| GRB       | `GRB_BASE_URL`, `GRB_TELNET_USERNAME`, `GRB_TELNET_PASSWORD`, opcional `GRB_TELNET_ARG0`      | Proxy telnet topologia de rede (Basic Auth)         |
| Critel    | `CRITEL_BASE_URL`                                                                             | Gráficos de desempenho de circuitos                 |
| Auth      | `AUTH_SECRET`, `AUTH_SESSION_DAYS`, `APP_TOUR_VERSION`                                        | JWT em cookie HTTP-only                             |

Exemplo GRB/Critel:

```dotenv
GRB_BASE_URL=http://200.255.253.12/grb/topologia_rede/www
GRB_TELNET_USERNAME=matricula
GRB_TELNET_PASSWORD=troque_me
# GRB_TELNET_ARG0=_]C<>:<;@>
CRITEL_BASE_URL=http://200.255.253.12/grb/critel
```

Regras de espelhamento: rule `.cursor/rules/emp-env.mdc` · skill `.cursor/skills/emp-align-env/SKILL.md`.

## 7. GRB — TELNET

Fluxo integrado em `/grb` (espelhado do botGrb):

1. **UF / região** → equipamento (catálogo AM/MA/PA ou hostname livre).
2. **Comando** — preset whitelist (`commandPresetId`); o servidor monta o texto, não aceita comando arbitrário.
3. Campos dinâmicos (IP, interface, VRF/VPRN, WORD) conforme o preset.
4. `POST /api/grb/execute` carrega HTML do console GRB, obtém tokens e executa via proxy telnet.
5. Saída exibida na página; apenas a **linha de eco do prompt** é substituída pelo comando enviado (resposta intacta).

### Plataformas

| Plataforma      | Equipamentos                      | Comandos                                                                          |
| --------------- | --------------------------------- | --------------------------------------------------------------------------------- |
| **Nokia SR OS** | Catálogo AM/MA/PA                 | Ping (router-instance VPRN) · STAFF: interfaces + BGP SR OS                       |
| **Cisco IOS**   | Hostname livre / fora do catálogo | Ping (todos) · STAFF: catálogo GRB legado (~95 `sel_cmds`) agrupado por categoria |

Categorias Cisco no select: Ping, Traceroute, Interfaces, BGP, VRF, OSPF, Rotas/CEF, Multicast, ARP, Políticas, WAN/controllers, Plataforma, Show.

### VPRN Nokia

- `GET /api/grb/vprn?eqpto=…` — lista `show service service-using vprn` (service-id + nome).
- Ping usa **nome** (`router-instance PRODUCTION:7776`).
- BGP VPRN STAFF usa **service-id** (`show router 7776 bgp neighbor …`).

## 8. Critel — gráficos de circuito

Fluxo em `/grb/critel`:

1. Usuário informa **designação** (formato `local/tipo/número`, ex.: `itz/ip/01816`).
2. `POST /api/grb/critel/graph` consulta o portal Critel legado:
   - `proc/pesquisa.php` — busca por designação
   - `proc/graficos.php` — metadados + URL do gráfico
   - `proc/graph.php` — PNG (sessão PHP)
3. UI exibe gráfico, período e sumário (média, máximo, percentis).

Código: `lib/critel/`, `components/grb/CritelPanel.tsx`, config em `lib/config/critel.ts`.

## 14. Troubleshooting

| Sintoma                 | Verificação                                                   |
| ----------------------- | ------------------------------------------------------------- |
| GRB/Critel timeout      | Rede até `GRB_BASE_URL` / `CRITEL_BASE_URL`; curl manual      |
| TELNET 403              | Comando restrito a staff; usuários comuns só ping             |
| Critel sem resultados   | Designação no formato `LOC/TIPO/NUM`; maiúsculas normalizadas |
| `api/saude` ERRO SIR    | `.env.local`, `npm run env:check`, `db:migrate`               |
| Worker `rowErrors` alto | Journal RAL/REC; restart após fix de scrape                   |
| UI antiga após pull     | `npm run build && sudo systemctl restart empresarial-next`    |

Erros de bootstrap e path: [deploy/README.md](../deploy/README.md#troubleshooting-erros-comuns).
Setup: [lab](2026-07-27-lab.md) · [produção](2026-07-26-deploy-producao.md).
